# Security Policy

## Repository Visibility

This project should remain **private** until:
- institutional ownership is confirmed
- legal and regulatory review is complete
- payment and evidence-handling policies are approved

## Sensitive Areas

Changes affecting the following require careful review:
- authentication and RBAC
- audit logging
- evidence storage
- payment request flow
- complaint decisions
- personal or vehicle data handling

## Reporting

Do not open public issues for:
- credential exposure
- payment callback vulnerabilities
- evidence access bypasses
- authorization flaws
- data retention or deletion defects

Report security concerns privately through the project owner or institutional supervisor.
